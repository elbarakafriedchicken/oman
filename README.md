🍗 مطعم البركة - المنيو الذكي (Al Baraka Smart Menu)

تطبيق ويب ذكي وسريع لمطعم البركة، يتيح للعملاء تصفح قائمة الطعام، تخصيص الوجبات، وإرسال الطلبات مباشرة عبر تطبيق الواتساب.

✨ المميزات (Features)

تحديث فوري للبيانات: القائمة مربوطة مباشرة بـ Google Sheets، أي تعديل في الشيت يظهر فوراً في الموقع بدون الحاجة لتعديل الكود.

الوضع الليلي (Dark Mode): واجهة مستخدم مريحة للعين تتكيف مع إعدادات جهاز المستخدم.

إدارة السلة (Cart Management): إمكانية إضافة الوجبات، تحديد الكميات، وإضافة ملاحظات أو إضافات (مثل الجبن، الصوصات، المشروبات).

تكامل مع الواتساب (WhatsApp Integration): تجميع الطلب بالكامل وإرساله كرسالة منسقة إلى رقم واتساب المطعم.

نظام أوقات العمل: الموقع يقرأ أوقات العمل من الشيت ويمنع الطلبات إذا كان المطعم مغلقاً.

تطبيق ويب تقدمي (PWA): يمكن للعملاء تثبيت الموقع كتطبيق على هواتفهم الذكية.

🛠️ التقنيات المستخدمة (Tech Stack)

HTML5 / CSS3 / Vanilla JavaScript: أساسيات الويب بدون أطر عمل معقدة لضمان أقصى سرعة.

Tailwind CSS: لتصميم الواجهة بشكل عصري ومتجاوب مع جميع الشاشات.

Phosphor Icons: لأيقونات الواجهة.

Google Sheets API (CSV Export): كقاعدة بيانات مجانية وسهلة التعديل للإدارة.

🚀 طريقة التشغيل وإدارة المنيو

تعديل المنتجات: قم بفتح ملف الـ Google Sheet المرتبط بالمشروع.

يمكنك إضافة أقسام جديدة، تعديل الأسعار، أو تغيير حالة توفر المنتج.

التغييرات تنعكس فوراً بمجرد عمل Refresh للموقع.

⚙️ إعدادات المتجر (من داخل الشيت)

يجب أن يحتوي الشيت على قسم باسم الاعدادات للتحكم في الآتي:

رقم الواتساب (بالرمز الدولي مثل: 96892018510)

وقت الفتح (مثال: 10:00)

وقت الغلق (مثال: 02:00)

وقت الاستلام (بالدقائق، مثال: 20)
